클래스 비공개

클래스를 비공개로 전환하면 수강생에게 노출되지 않으며, 신규 신청을 받을 수 없습니다. 기존 신청 일정은 그대로 유지됩니다.

  • 비공개 처리 후 클래스 목록에서 숨김 처리됩니다.
  • 기존 신청 정보와 일정은 유지됩니다.
  • 필요 시 다시 공개로 전환할 수 있습니다.
